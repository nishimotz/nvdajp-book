Windows の操作と設定の基本
------------------------------

新しい Windows と NVDA
~~~~~~~~~~~~~~~~~~~~~~

2015年に Windows 10 が登場し、Windows 標準のスクリーンリーダーである「ナレーター」の改良も進みました。

2021年に Windows 11 が登場し「コンピューターの簡単操作」の名称が「アクセシビリティ」に変更されました。

これらの Windows のアップデートを通じて、新しいアクセシビリティ API への移行が進められてきました。

UI オートメーションとよばれる新しい技術には、NVDA よりも「ナレーター」の対応の方が進んでいることもあります。

NVDA は従来の API に対応したスクリーンリーダーとしての高い性能を保ちながら、新しい API に対応したスクリーンリーダーとしても開発が続けられています。

この章では Windows 11 に基づいて Windows の操作と設定の基本を紹介します。Windows 10 からの変更点もいくつか含みます。

マイクロソフトのサイトには Windows のキーボードショートカットキーの一覧や視覚障碍者向けのマニュアルがあります：

-  `Microsoft アクセシビリティ <https://www.microsoft.com/ja-jp/accessibility>`__
-  `Windows のキーボード ショートカット <https://support.microsoft.com/ja-jp/windows/windows-%E3%81%AE%E3%82%AD%E3%83%BC%E3%83%9C%E3%83%BC%E3%83%89-%E3%82%B7%E3%83%A7%E3%83%BC%E3%83%88%E3%82%AB%E3%83%83%E3%83%88-dcc61a57-8ff0-cffe-9796-cb9706c75eec>`__

Windows キー
~~~~~~~~~~~~~~~~

まず Windows キーの機能を整理します。

Windows キーを押すと「スタートウィンドウ」が開きます。
スタートウィンドウを閉じるには、もう一度 Windows キーを押すか、Esc キーを押します。

また、Windows キーと他のキーを同時に押すと、以下のような機能が利用できます：

-  Windows+D デスクトップにフォーカスを移動
-  Windows+B 通知領域にフォーカスを移動
-  Windows+T タスクバーにフォーカスを移動
-  Windows+X
   クイックリンクメニューを表示（「シャットダウンまたはサインアウト」など。内容は Windows 11 で一部変更）
-  Windows+A クイック設定を表示
-  Windows+N 通知センターを表示
-  Windows+E エクスプローラーを起動
-  Windows+U アクセシビリティ設定を起動
-  Windows+R 「ファイル名を指定して実行」を起動
-  Windows+I 設定を起動
-  Windows+S 検索を開く (Windows 11 ではスタートメニューとは独立)

複数の入力メソッド（日本語入力システムなど）を使っている場合は、以下の操作で切り替えることができます。

-  Windows+スペース：入力メソッドの切り替え

入力方法エディター、入力メソッド、単に「キーボード」と呼ばれることもあります。

アプリを切り替える操作をまとめます：

-  Alt+Tab：Alt を押し続けている間、Tab でアプリケーションの切り替え
-  Windows+Tab：タスクビュー（仮想デスクトップの管理とアプリの切り替え）。左右矢印キーと Enter で切り替え
-  Alt+F4：現在のアプリを終了

Windows 11 は複数のデスクトップ画面（仮想デスクトップ）を使えます。

メニューとリスト
~~~~~~~~~~~~~~~~~~~~

Windows+X で開くコンテクストメニューを例に、メニューの操作方法を確認します。

-  上下矢印キー：メニューの項目の移動
-  Enter：選択中のメニュー項目の実行
-  Esc：メニューを閉じる

メニューは開いた直後の状態では最初のメニュー項目にフォーカスが移動していないことがあります。
その場合は、最初に下矢印キーで先頭の項目に移動します。
また、一番上または一番下で、さらに上や下に移動しようとすると、反対側の端に移動できる場合が多いです。

メニュー項目にはサブメニューという項目が含まれる場合があります。

-  右矢印キー：サブメニューの中に（子の項目に）入る
-  左矢印キー：サブメニューから（親の項目に）戻る

メニュー項目には「アクセラレーターキー」が割り当てられている場合があります。
例えば Windows のコンテクストメニューには「シャットダウンまたはサインアウト(U)」という項目があり、その中にはさらに「シャットダウン(U)」という項目があります。
この場合、次の操作でシャットダウンを実行できます。

-  Windows+X U U

次に Windows+I で開く「設定」から Tab を1回押して、リストの操作方法を確認します。

リストにも複数のリスト項目が含まれています。
メニューと同じように矢印キーで移動できますが、すべての項目に移動したい場合に、左右の矢印キーを使った方がよい場合があります。
また、リスト項目は Enter に加えてスペースでも実行できる場合があります。

Windows 11 の「設定」は、左側にナビゲーションペイン（カテゴリ一覧）、右側に選択したカテゴリの設定項目が表示されるレイアウトが基本です。ウィンドウ幅に応じて多少レイアウトは調整されます。

ダイアログボックスとボタン
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Windows+R で「ファイル名を指定して実行」を開いてください。

フォーカスは Tab キーで順番に次の項目に移動できます。
この順番はふつうは画面の上から下、左から右に決められています。 Tab キーで行き過ぎたときには Shift+Tab キーで逆方向に移動できます。
逆方向移動は先頭の項目から一番最後の項目に移動するときにも便利です。

NVDA+Tabキーで、現在のフォーカス位置の項目の読み上げを行います。
読み上げの中止は Ctrl キーで、中断は Shift キーでできます。
中断したあとでShiftキーをもう一度押すと、続きを読み上げます。

一般的なダイアログボックスは、Enterキーを押すと変更を保存して閉じる、Escキーを押すと変更をキャンセルして閉じる、という操作になっています。

例えば「OK」と「キャンセル」のボタンがあるときに、 ダイアログの操作を Enter や Esc で行うのではなく、 確実にどちらかのボタンを押したければ、
ボタンにフォーカスを移動して、スペースを押してください。

ダイアログに表示される情報には、フォーカスの移動だけでは読み上げられないものがあります。
必要に応じて「アクティブウィンドウの読み上げ」「ナビゲーターオブジェクトの移動」を実行する必要があります。

Windows 11 の「設定」にも、ボタンのように機能する「リンク」要素があります。
何かを実行したり、別の設定画面に移動するために使われます。

リンクはボタンのように四角い枠で囲まれていないテキストです。
文字の色や配置だけで「クリックできる」ことを表現しています。 リンクは Enter またはスペースでアクションを実行できます。

例えば「設定」「システム」「通知」の中に「通知設定」などの項目があり、
これを実行すると、アプリごとの通知設定画面に移動します。（Windows 11 ではクイック設定のボタン編集は「クイック設定」パネル自体で行います）

コンボボックス
~~~~~~~~~~~~~~~~~~

「ファイル名を指定して実行」ダイアログには「コンボボックス 折りたたみ」があります。

コンボボックスには折り畳まれた（クローズの）状態と展開された（オープンの）状態があります。
キーボードではコンボボックスが折り畳まれた状態のまま矢印キーで操作できます。
上下矢印キーを押しても何も読み上げないときは、これ以上選択肢がないことを意味します。

また、コンボボックスは Alt+下矢印 で展開の状態に切り替えることもできます。
展開すると、上矢印キーと下矢印キーで項目の選択、Enter で決定、Esc でキャンセルです。

Windows 11 のコンボボックスも試してみましょう。

Windows+I で「設定」を開き、左側のナビゲーションで「アクセシビリティ」を選択し、Enter を押します。
右側のペインで Tab キーを使い「ナレーター」に移動して Enter を押します。

さらに Tab キーで移動し、「ナレーターの音声を選択する」の下にある「音声」のコンボボックス（例: 「Microsoft Ayumi - 日本語 (日本)」）に移動します。

上下の矢印キーでインストールされている他の音声（例: 「Microsoft Ichiro - 日本語 (日本)」）に切り替えてみてください。

また Alt+下矢印 で展開してから上下矢印で移動、Enter で項目を選べることも確認してください。

チェックボックスとトグルボタン
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

チェックボックスはオンとオフの2つの状態を持つコントロールです。 NVDA ではそれぞれの状態を「チェック」「チェックなし」と読み上げます。
切り替えるには、そこにフォーカスを移動して、スペースを押します。

さきほどの「ナレーター」の設定画面には、多くの設定項目がチェックボックスやトグルボタンで用意されています。例えば、

「ナレーター カーソルにテキスト挿入ポイントに従わせる」

のようなチェックボックスがあります。

Windows 11 でもトグルボタンは広く使われています。NVDA
ではトグルボタンの状態を「オン」「オフ」または「押されています」「押されていません」のように読み上げます（設定によります）。
切り替えるには、チェックボックスと同じく、スペースを押します。

例えば「設定」>「Bluetooth とデバイス」>「Bluetooth」のオン/オフはトグルボタンです。
設定の変更はすぐに有効になることが多いです。

スライダー
~~~~~~~~~~~~~~

スライダーは NVDA の音声設定にも使われていますが、
数値を視覚的に表現して、値を変更できるようになっています。
キーボードでは上下または左右の矢印キーで値を増やしたり減らしたりできます。
EndキーとHomeキーで最小値や最大値に変えることもできます。
キーを押すたびに数値を読み上げます。

Page Up, Page Downキーによる値の変更は、アプリやコントロールによります。

さきほどの「ナレーター」の設定画面には「速度」「ピッチ」「音量」のスライダーがあります。

これらのスライダーの値を変更して、設定をカスタマイズできます。変更はすぐに反映されることが多いです。

この画面の設定は NVDA ではなく Windows のナレーターの音声設定です。

スタートメニューと検索
~~~~~~~~~~~~~~~~~~~~~~~~~~

ここでは Windows 11 のスタートメニューと検索機能を紹介します。

Windows キーを押すとスタートメニューが表示されます。デフォルトでは画面中央下部に表示されます。

スタートメニューの主な構成要素は以下の通りです。

-  検索ボックス: 上部にあり、アプリ、ファイル、設定、Web 検索などができます。Windows+S でも直接開けます。
-  ピン留め済み: よく使うアプリをピン留めしておくエリアです。Tab キーや矢印キーで移動し、Enter で起動します。
-  おすすめ: 最近使ったファイルや新しくインストールしたアプリなどが表示されます。
-  すべてのアプリ ボタン: 右上にあるボタンで、これを Enter するとインストールされているアプリの一覧が表示されます。
-  アカウント ボタン: 左下にあり、アカウント設定の変更、ロック、サインアウトができます。
-  電源 ボタン: 右下にあり、スリープ、シャットダウン、再起動ができます。

「すべてのアプリ」リストでは、アプリ名がアルファベット順（日本語環境では五十音順も考慮）に並びます。
目的のアプリ名の頭文字を入力すると、その文字で始まる最初のアプリにジャンプできます。
上下矢印キーで移動し、Enter で起動します。フォルダ構造になっている場合もあります（例: NVDA フォルダ）。

Windows 11 では、ピン留めできるのはアプリのアイコンです。

エクスプローラー
~~~~~~~~~~~~~~~~~~

Windows 11 のエクスプローラーはデザインが新しくなり、リボンの代わりにコマンドバーが採用されました。タブ機能も追加されています。

F6 キーを押すと、主要なペイン間（ナビゲーションウィンドウ、ファイルリスト、アドレスバー、検索ボックスなど）を移動できます。

主なキー操作：

-  Ctrl+L または Alt+D：アドレスバーに移動
-  Alt：コマンドバーのキーヒントを表示（例: Alt+V で表示メニュー）
-  Ctrl+T：新しいタブを開く
-  Ctrl+W：現在のタブを閉じる
-  Ctrl+Tab：次のタブに移動
-  Ctrl+Shift+Tab：前のタブに移動
-  Ctrl+Shift+数字 (1-8): 表示レイアウトの切り替え（例: Ctrl+Shift+6 で詳細表示）
-  Alt+Enter: 選択中のアイテムのプロパティを開く
-  Shift+F10 または アプリケーションキー: コンテキストメニューを表示（Windows 11 では簡略化されたメニューがまず表示され、「その他のオプションを表示」で従来のメニューも開けます）

コマンドバーの操作：

-  Alt キーを押すと、コマンドバーの各項目にキーヒント（アルファベットや数字）が表示されます。対応するキーを押すとその機能が実行されたり、サブメニューが開いたりします。
-  Tab キーや矢印キーでも移動できます。

ファイル名の拡張子の表示設定は、コマンドバーからアクセスできます。

-  コマンドバーの「表示」メニュー → 「表示」サブメニュー → 「ファイル名拡張子」

Windows の操作と設定のまとめ
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

過去の Windows でコントロールパネルにあった機能の多くは、Windows 11 では「設定」アプリに統合されています。
一部の古い設定項目はまだコントロールパネルに残っていますが、基本的な設定は「設定」アプリで行います。

設定アプリは Windows 11 のデザインに合わせて更新されています。
マウス、タッチ、キーボードでの操作が考慮されています。
多くのアプリでは、Alt キーでアクセスできる従来のメニューバーの代わりに、アプリ固有のメニューボタンやコマンドバーが使われています。

重要な設定項目について補足しておきます。

既定のアプリ（Web ブラウザなど）を変更するには、以下を使います。

-  設定 > アプリ > 既定のアプリ

ここで、ファイルの種類やリンクの種類ごとに既定のアプリを設定するか、アプリを選んでそのアプリが既定で開く項目を設定します。Web ブラウザの場合は、ブラウザアプリ（例: Firefox, Chrome）を選び、「既定値に設定する」ボタンを押すのが簡単です。

Windows Update に関しては以下を知っておくとよいでしょう。

-  設定 > Windows Update

ここで更新プログラムの確認やインストール、更新履歴の表示ができます。

-  設定 > Windows Update > 詳細オプション > アクティブ時間

この設定でアクティブ時間を指定すれば、その時間帯に Windows Update による自動再起動が行われるのを防ぐことができます。Windows 11 Home でもこの設定は利用可能です。

-  設定 > システム > トラブルシューティング > その他のトラブルシューティング ツール > Windows Update

Windows Update に関する問題が発生した場合、このトラブルシューティング ツールを実行すると問題が解決することがあります。
